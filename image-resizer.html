📖 What is Image Resizing?

Image resizing is the process of changing the dimensions and file size of an image. It is essential for optimizing images for different platforms, reducing file size, and improving website performance.

Common Image Size Requirements

  • Passport Photo: 2x2 inches (600x600px) | < 1 MB
  • CNIC Front/Back: 600x400px | < 500 KB
  • Aadhaar Card: 600x400px | < 500 KB
  • Result Card: 800x600px | < 1 MB
  • Certificate: 1200x900px | < 2 MB
  • Instagram Post: 1080x1080px | < 5 MB
  • YouTube Thumbnail: 1280x720px | < 2 MB

🔒 Privacy: All processing is done locally in your browser. No image is uploaded to any server.
