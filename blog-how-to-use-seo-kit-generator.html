Tab 1: Meta Tags – Your SEO Foundation

The Meta Tags tab is the most important section. It generates the core SEO tags that every webpage needs.

Fields Explained

  • Page Title: This appears in search results and browser tabs. Keep it under 60 characters. Aim for 50–60 characters for best results.
  • Meta Description: This appears below your title in search results. Keep it under 160 characters. Aim for 150–160 characters.
  • Keywords: Comma-separated keywords that describe your page. (Optional but helpful.)
  • Author: Your name or brand name.
  • Robots: Choose from index/follow, noindex/follow, index/nofollow, or noindex/nofollow.
  • Canonical URL: The preferred URL for this page (prevents duplicate content issues).

Real-Time Character Counter

As you type, the character counter shows you exactly how many characters you've used. If you exceed 60 for the title or 160 for the description, the counter turns red to alert you.

Tab 2: Schema Markup – Rich Snippets & Better CTR

Schema Markup (structured data) helps search engines understand your content and can trigger rich snippets in search results.

Supported Schema Types

  • Article: For blog posts, news articles, and reviews.
  • Product: For e-commerce products with price, currency, and availability.
  • Recipe: For food blogs with cooking time, prep time, and ingredients.
  • FAQPage: For Frequently Asked Questions pages.
  • LocalBusiness: For local businesses with address, phone, and hours.
  • Person: For author profiles with job title and affiliation.
  • Event: For conferences, webinars, or meetups with dates and location.

How to Use

  1. Select a schema type: Choose the type that best matches your content.
  2. Fill in the fields: Enter the headline/name, description, and image URL. Additional fields will appear based on the type you selected.
  3. Click Generate: The tool creates valid JSON-LD schema markup.

⚠️ Important: Always test your schema using Google's Rich Results Test before deploying.

Tab 3: Robots.txt – Crawl Control

The Robots.txt tab helps you create a file that tells search engine crawlers which parts of your website they can access.

Fields Explained

  • User-agent: Specify which crawlers the rules apply to. Use * for all crawlers.
  • Allow paths: Paths that crawlers can access (one per line).
  • Disallow paths: Paths that crawlers should not access (one per line).
  • Sitemap URL: The URL of your sitemap.xml file.
  • Crawl-delay: The number of seconds between crawl requests (reduces server load).
  • Host: Your primary domain name.

Best Practices

  • Always include a sitemap reference.
  • Block duplicate content (like admin sections or staging environments).
  • Avoid blocking CSS and JavaScript files (Google needs these to render your pages).
  • Test your robots.txt using Google Search Console.

Tab 4: Sitemap – Help Search Engines Discover Your Content

The Sitemap tab generates an XML sitemap that lists all your important pages.

How to Use

  2. Pages: List your pages one per line (e.g., /, /about, /contact).
  3. Click Generate: The tool creates a complete sitemap.xml file.
  4. Download XML: Save the file as `sitemap.xml` and upload it to your server.

💡 Pro Tip: Submit your sitemap to Google Search Console and Bing Webmaster Tools for faster indexing.

Tab 5: Open Graph – Control Social Media Sharing

Open Graph tags control how your content appears when shared on Facebook, LinkedIn, and WhatsApp.

Fields Explained

  • OG Title: The title that appears when your content is shared.
  • OG Description: The description that appears below the title.
  • OG Image: A high-quality image (1200×630px recommended).
  • OG URL: The canonical URL of your page.
  • OG Type: Choose from website, article, product, or video.
  • Site Name: Your website name.

Best Practices

  • Always add an OG image. Posts without images get 10x less engagement.
  • Use a 1200×630px image. This is the optimal size for Facebook and LinkedIn.
  • Match your OG title to your page title. Consistency is key.

Tab 6: Twitter Cards – Optimize for X/Twitter

Twitter Cards control how your content appears when shared on X (formerly Twitter).

Fields Explained

  • Twitter Card Type: Choose from summary, summary_large_image, or app.
  • Twitter Title: The title that appears in the card.
  • Twitter Description: The description that appears in the card.
  • Twitter Image: An image for the card (summary_large_image is recommended).
  • Twitter Site: Your Twitter handle (e.g., @getage247).
  • Twitter Creator: The content author's Twitter handle.

💡 Pro Tip: Use `summary_large_image` for better engagement. It displays a large image and gets 2-3x more clicks than `summary`.

Tab 7: Breadcrumb Schema – Enhance Search Results

Breadcrumb Schema adds structured breadcrumb navigation to your search results, helping users understand your site structure.
